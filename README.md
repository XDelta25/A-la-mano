# A la mano

Plataforma web para encontrar servicios y oficios (carpintería, herrería, etc.).

## Requisitos
- Node.js 24 (LTS)

## Cómo correrlo
1. npm install
2. npm run dev
3. Abrir http://localhost:3000

## Estructura
- app/ → páginas
- components/ → piezas reutilizables
- lib/ → datos y funciones
